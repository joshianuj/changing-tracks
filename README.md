# changing-tracks

10 years as a full-stack/infra engineer (React, Node, Kubernetes, GKE, CI/CD).
This is the public log of an 8-10 month deep dive into ML systems, LLM
internals, distributed training, and interpretability — the gap between
"infra engineer" and "systems engineer at a research org."

## Why
I've been a full-stack/infra engineer for 10 years. I'm good at it, but
I want to reinvent myself — build something new on top of what I already
know.

This repo is me learning ML and AI systems from the ground up, in public,
over the next 8-10 months. No pretending I already know this — just the
actual process, as it happens.

## Structure

- `phase-1-foundations/` — deep learning & PyTorch basics
- `phase-2-transformers/` — attention, nanoGPT, scaling laws
- `phase-3-distributed/` — parallelism, memory efficiency, inference serving
- `phase-4-interpretability/` — mech interp, RLHF
